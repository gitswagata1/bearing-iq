How the model works

Data
Synthetic hourly RMS vibration (mm/s), exponential degradation + noise. Not plant data.
Features
RMS vibration trend (last 120 h) · Baseline vibration (median of first 48 h) · Time since install (h)
Model
Exponential degradation curve v(t) = v0 + exp(a + b·t), fitted by least squares on log(v − v0); failure = crossing 7.1 mm/s.
Target
Remaining useful life (hours) until the alarm threshold is crossed
Uncertainty
Residual bootstrap (300 refits) → P10/P50/P90 RUL and P(failure within 72 h)

60 predictions. Backtest on 20 synthetic run-to-failure histories not used for the on-screen assets, predicting at 60%, 75% and 90% of life. Synthetic data follows the same model family, so these numbers are optimistic versus real sensors.

Known limitations

  • Single sensor channel; no temperature/load covariates yet
  • Assumes monotonic exponential degradation; maintenance resets are not modelled
  • Validated only on synthetic data; needs real run-to-failure data (e.g. bearing test-rig datasets) before any claim of accuracy
